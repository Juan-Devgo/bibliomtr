# web

Frontend de bibliomtr: React + TypeScript + Vite, TanStack Query, D3, KaTeX, Recharts, MUI y shadcn/ui.

```bash
npm install
npm run dev     # http://localhost:5173, /api -> http://localhost:8080
npm run build
npm run lint
```

Agregar componentes de shadcn/ui con `npx shadcn@latest add <componente>`.
